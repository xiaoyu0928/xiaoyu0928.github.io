# Open Science

This directory hosts open research materials from Xiaoyu Chen's research group.

Materials are organized by publication and may include:

- de-identified data and data dictionaries;
- analysis code and reproducibility instructions;
- study instruments and supporting documentation;
- author-accepted manuscripts or other full-text versions that may legally be shared.

## Repository structure

- [`data-and-code/`](data-and-code/) - data, code, instruments, and documentation
- [`papers/`](papers/) - legally shareable full-text manuscripts

## Release principles

Materials are released only when participant consent, research ethics requirements,
publisher policies, copyright, and third-party data licenses permit sharing. Each
publication-specific folder should include a README describing the citation,
contents, license, software requirements, and any access restrictions.
