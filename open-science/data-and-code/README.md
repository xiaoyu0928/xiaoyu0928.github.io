# Data and Code

Publication-specific research packages will be added here. Each package should use
a stable folder name such as `year-short-title` and include:

- a full citation and DOI;
- a data dictionary or clear description of any non-shareable source data;
- analysis code with software and package versions;
- reproducibility instructions;
- an appropriate data and code license;
- ethics, consent, and access notes where applicable.
